# Tic-tac-toe
[An intermediate tic-tac-toe JS exercise from The Odin Project.](https://www.theodinproject.com/lessons/node-path-javascript-tic-tac-toe)

Focus was on using as few global variables as possible, using **factory functions**, and get to know the **module pattern/IIFE**.

## Features
* Define two players
* Play tic-tac-toe
* Reset game
